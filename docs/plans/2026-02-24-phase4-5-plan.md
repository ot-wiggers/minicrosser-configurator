## Task 4: Add colorVariantImages table + Convex CRUD

**Files:**
- Modify: `convex/schema.ts`
- Create: `convex/colorVariantImages.ts`

**Step 1: Add table to schema**

In `convex/schema.ts`, add:
```ts
colorVariantImages: defineTable({
  baseModelId: v.id('baseModels'),
  optionId: v.id('options'),
  imageStorageId: v.id('_storage'),
  sortOrder: v.number(),
})
  .index('by_model_option', ['baseModelId', 'optionId'])
  .index('by_model', ['baseModelId'])
```

**Step 2: Create convex/colorVariantImages.ts**

Queries:
- `listByModelAndOption(baseModelId, optionId)` — returns images with URLs, sorted by sortOrder
- `listByModel(baseModelId)` — all images for a model (admin use)

Mutations:
- `create({ baseModelId, optionId, imageStorageId, sortOrder })` — add new image
- `remove(id)` — delete image + storage file
- `updateSortOrder(id, sortOrder)` — reorder
